# Tipografia

Outfit = interface e títulos. Geist Mono = preços, IDs, timestamps, KPIs. Sem Inter/Arial na UI nova.

Hierarquia por **peso**, não por tamanho gritante.

## Escala

| Papel | Size | Weight | Tracking | Leading | Uso |
|-------|------|--------|----------|---------|-----|
| Display | 44px | 700 | -0.04em | 48px | Título de página |
| Section | 22px | 600 | -0.03em | 28px | Blocos, tabelas, modal title |
| Body | 15px | 400 | 0 | 24px | Listas, descrições |
| Label / meta | 13px | 500 | 0 | 18–20px | Chips, botão, campo |
| Caps table | 11px | 500 | 0.08em | 14px | Header de coluna |
| Pill | 12px | 500 | 0 | 16px | Status |
| KPI | 28px | 600 | -0.04em | 32px | Geist Mono |
| Dados inline | 22px | 500 | -0.02em | 28px | Geist Mono |

Tokens Paper extras: `lg 18`, `3xl 36`. Weights: 400 / 500 / 600 / 700.

## Regras

- Número de KPI e `wrk_*` = mono.
- Label de grupo nav (`OPERAÇÃO`, `CATÁLOGO`) = caps + tracking wide + muted.
- Wordmark rail: **Cestou Ops** Outfit 500 14px — não Geist Mono.
- Texto longo nunca em Buoy/Harbor; acento só em CTA, foco, pill.
