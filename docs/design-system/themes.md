# Temas

Paper: tokens globais = **light**. Dark = hex pintados no artboard, mesma medida.

No código: `[data-theme="light"]` (default) e `[data-theme="dark"]` em `tokens.css`.

## O que muda

Cor de superfície, texto, borda, foco (Harbor → `#7BA8C4`), pills, scrim.

## O que não muda

Espaço, raio, type scale, altura de botão/input, largura de sidebar/modal/toast. Primary **fill** do botão permanece `#2F5F7A`.

## Contraste

- Light: Ink em Paper.
- Dark: `#E8EEF2` em canvas `#15232E`.
- CTA Harbor: texto branco, não Ink.
- Buoy não é texto de parágrafo.
